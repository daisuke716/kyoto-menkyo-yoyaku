# 京都府運転免許試験・学科試験 自動予約スクリプト
## 概要
本プロジェクトは、京都府警察運転免許予約サイトを対象とした 免許更新・学科試験のインターネット自動予約ツールです。
個人情報の自動入力、空き枠の検索、予約確定までを自動で実行します。  
### ⚠️ 本ツールは個人の学習・研究目的のみです。
### 商用利用・大量アクセスは禁止されています。


# Kyoto License Exam Auto Booking Tool
## Overview
This project is an automation tool for booking driving license updates and written exams through the Kyoto Police Internet reservation system.  
It automatically fills in personal information, searches for available dates and time slots, and optionally confirms the reservation.  
### ⚠️ This software is for personal learning and research purposes only.
### Commercial or large-scale use is strictly prohibited.
